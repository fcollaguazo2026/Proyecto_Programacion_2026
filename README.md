Sistema de Gestión de Clientes para Gimnasio

Aplicación desarrollada en C++ utilizando Qt Creator para la administración de clientes de un gimnasio. El sistema permite realizar operaciones CRUD (Crear, Leer, Actualizar y Eliminar) sobre los registros de clientes mediante una interfaz gráfica intuitiva.

Funcionalidades principales
Registro de clientes con ID, nombre, edad, plan, duración y fecha de inscripción.
Edición y actualización de información de clientes.
Eliminación de registros de clientes.
Búsqueda de clientes por ID, plan o fecha de inscripción.
Visualización de los resultados en una tabla interactiva.
Validación de datos para evitar registros incompletos o duplicados.
Almacenamiento persistente de la información en archivos de texto.
Interfaz gráfica con tema oscuro y botones personalizados.
Tecnologías utilizadas
C++
Qt Framework
Qt Widgets
QFile y QTextStream para persistencia de datos
QTableWidget para visualización de registros
Objetivo del proyecto

Facilitar la gestión de clientes de un gimnasio mediante una aplicación de escritorio sencilla, permitiendo administrar la información de manera rápida, organizada y eficiente.
